# 同步官方 v0.2.19

日期：2026-10-29。`0.2.19` 分支以当前已发布的自定义 `0.2.16`（`10636ebd9fcce18c7c0c1640a6e65a1640ab683e`）为基线，合并官方正式标签 [v0.2.19](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.19)（`dece26153621959ccd7635814f4b2d08304e681a`），保留双方提交历史。

## 同步内容

- 包含官方受限管理员 API Key、GPT-6.1 Terra、图片按张计费、Gemini 同账号重试设置、Grok 模型目录诊断及相关网关修复。
- 保留菜单隐藏、用户管理和 `readonly_admin` 角色；完整管理员及只读管理员的 JWT 会话继续遵循面板限流豁免设置，受限管理员 API Key 按密钥独立限流且不享有该豁免。
- 保留 Azure Redis Cluster、键命名空间和多节点共享报表缓存兼容，重新生成 Wire 依赖接线并接入官方受限密钥存储。
- 保留 GPT / Gemini / Antigravity / 多实例 Kiro 汇总、账号去重和额度进度；页面继续仅显示汇总，不显示单账号明细。
- 保留不可点击的版本号、隐藏顶栏余额、取消登录条款、新用户引导及部署运营合规确认，以及 iframe 跨节点缓存刷新。
- 官方标签内 `backend/cmd/server/VERSION` 仍为 `0.2.18`；本分支修正为 `0.2.19`，使自定义提交的默认构建版本正确。
- 其他未发布功能分支和旧工作区未提交修改未纳入本次合并。
- 补齐报表服务退出清理的空依赖兼容及测试接线。原有内存上限测试改用独立进程测量，避免其他测试的后台任务干扰全进程堆统计；保留 20000 次请求、无直接查库断言和原 8 MiB 阈值。

## 数据库与兼容变化

从当前自定义 0.2.16 升级会自动执行 3 个新增 SQL 迁移：

| 迁移 | 影响 |
| --- | --- |
| `246_enable_gemini_image_generation_groups.sql` | 将已有 Gemini / Antigravity 分组的 `allow_image_generation=false` 改为 `true`；不修改 OpenAI / Composite 分组。部署前确认是否需要保留禁用生图策略。 |
| `247_scoped_admin_api_keys.sql` | 新建受限管理员密钥表，保存摘要、权限策略、IP 限制、过期和撤销状态等信息。 |
| `248_group_image_count_billing.sql` | 新增分组 `image_count_billing` 字段，默认关闭，不主动启用按张计费。 |

Gemini 默认模型目录移除停用的 2.0 / 2.5 系列和 `gemini-3-pro-preview`。仍需使用这些名称的账号，应显式配置白名单或模型映射；连接测试默认模型为 `gemini-3.5-flash`。

受限管理员 API Key 与只读管理员账号是两种身份：密钥由完整管理员会话创建，并按明确授权查询或操作资源；只读管理员继续使用原用户角色登录。受限密钥默认不能访问未纳入官方权限目录的自定义账号汇总报表，完整管理员和只读管理员的 JWT 会话可查看报表。
